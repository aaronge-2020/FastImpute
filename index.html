Methodology

What FastImpute calculates and how to read the output

Back to analysis

Reference-free genotype imputation

FastImpute uses pretrained, chromosome-specific linear regression models to predict missing PRS313 variants from observed genotypes. Models were trained on 1000 Genomes data using input variants linked to the 23andMe v5 panel. Observed PRS313 dosages are retained when available.

Simulation trials

Missing input genotypes are sampled using the reference minor allele frequencies. Each trial repeats imputation and scoring. The table reports the mean, median, population standard deviation, minimum, and maximum across those trials. The distribution shows this sampling variation.

Five score outputs

The existing PRS313 scoring pipeline returns overall breast cancer, ER-positive, ER-negative, hybrid ER-positive, and hybrid ER-negative scores. ER refers to estrogen receptor status. Scores are weighted sums of allele dosages, not individual cancer probabilities or calibrated risk percentiles.

Data and privacy

The selected file is read in browser memory. Genetic data is not sent to an analysis server or saved by this page. Model weights, reference tables, and calculation libraries are downloaded when needed. Exporting results saves a CSV to your device.

Limitations

This is a research baseline for the 23andMe v5 panel. Performance can vary with ancestry, genotyping platform, missingness, and the training data. Simulation variability does not capture every source of model error. Results are not a diagnosis or clinical risk assessment.
